# Contributing to EntoWing

EntoWing is currently an early prototype. Small, well-documented contributions are easier to review than broad unsourced changes.

## Scientific corrections

Please include:

- the family, genus, and species when known;
- the exact vein, cell, node, or branch statement concerned;
- the nomenclatural system being used;
- a stable publication link, DOI, manual page, or other authoritative source;
- whether the proposed change concerns terminology, homology, topology, or representative morphology.

Do not generalise a structure from one representative species to an entire family without explicit evidence.

## Interface and code changes

1. Create a focused branch.
2. Keep the Scientific mode readable and the Nocturnal mode accessible.
3. Test mouse, keyboard, and touch interactions when changing wing selection or the phylogeny board.
4. Run `npm run build` before opening a pull request.
5. Explain the visible behaviour before and after the change.

## Specimen images

Only contribute images that can legally be redistributed. Include the creator, specimen or collection identifier when available, source, licence, and required attribution. Do not commit private locality information or unpublished specimen data without permission.
